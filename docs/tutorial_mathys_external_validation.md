# Mathys External Validation Tutorial

Mathys 2019 is handled as CSV count and covariate files:

- `GSE138852_counts.csv.gz`
- `GSE138852_covariates.csv.gz`

Run the CSV inspection first, then target-gene extraction, feature aggregation, and external feasibility testing. Current Mathys sample-level validation should be interpreted cautiously when the inferred sample-unit count is small.
