# Limitations

NeuroFate is a research platform, not a clinical diagnostic tool.

Current limitations include:

- External validation remains preliminary where sample-level units are few.
- Target-gene panels are biologically motivated but narrow.
- Cross-cohort harmonization depends on source metadata quality.
- Donor-level modeling reduces pseudo-replication but cannot replace independent clinical validation.
- Causal claims require causal design and are not implied by association models.
