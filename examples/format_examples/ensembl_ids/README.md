# Ensembl-ID Example

Run:

```bash
neurofate run \
  --expression examples/format_examples/ensembl_ids/expression.tsv \
  --metadata examples/format_examples/ensembl_ids/metadata.tsv \
  --outdir results/examples/ensembl_ids
```

This example demonstrates curated NeuroFate Ensembl-to-symbol mapping.
