# Code of Conduct

NeuroFate follows a contributor covenant style expectation: be respectful, constructive, and precise.

## Expected Behavior

- Use welcoming and professional language.
- Respect different expertise levels and scientific perspectives.
- Keep critique focused on evidence, code, documentation, and reproducibility.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Publishing private information without permission.
- Deliberately misrepresenting software capabilities or validation evidence.

Concerns can be raised with project maintainers through the repository issue tracker or private project channels.
